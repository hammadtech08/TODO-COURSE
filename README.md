# 📝 Ed's Todo List

A clean, responsive Todo List web app with dark mode, local storage support, and inline editing.

---

## ✨ Features

- ✅ **Add Todos** — Type and press `+` to add a task
- 🗑️ **Delete Todos** — Remove any task with the trash button
- ✔️ **Complete Todos** — Mark tasks as done with the check button
- ✏️ **Edit Todos** — Double-click (desktop) or double-tap (mobile) on any task to edit it inline
- 🔍 **Filter Todos** — Filter by All / Completed / Uncompleted
- 🌙 **Dark Mode** — Toggle between light and dark theme
- 💾 **Local Storage** — All todos and theme preference are saved in the browser

## 🚀 How to Run

1. Clone or download this project
2. Open `index.html` in any browser

> No build tools or dependencies needed — pure HTML, CSS, and JavaScript.

---

## 🖥️ Desktop Preview

- Input bar and filter are on the same row
- Todos display in a centered list
- Hover effects on buttons and filter dropdown

## 📱 Mobile Responsive

- Input + Add button on the same row (no gap)
- Filter dropdown on the next line, right-aligned
- Todos stretch to full width for easy tapping
- Double-tap to edit works on touch screens

---

## 🌙 Dark Mode

Click the **moon icon** (🌙) in the top-right corner to toggle dark mode.  
Your preference is saved automatically and restored on next visit.

---

## ✏️ How to Edit a Todo

| Device | Action |
|--------|--------|
| Desktop | Double-click on the todo text |
| Mobile | Double-tap (two quick taps) on the todo text |

Press **Enter** or tap outside to save the edit.
